# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a vulnerability

Report privately through GitHub private vulnerability reporting: https://github.com/ahmed-essawy/disk-cleanup/security/advisories/new

Do not open a public issue for a vulnerability.

## What counts

- A rule or code path that could delete user data.
- A Critical item that can be deleted.
- A way to bypass the refusal of Critical ids.
- Writing outside the output folder during a scan.
- Any elevation attempt.
